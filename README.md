# Spreadsheet simulation in OCaml

![CI](https://github.com/FranklinChen/spreadsheet-ocaml/actions/workflows/ci.yml/badge.svg)

This is a packaged up version of the highly imperative dataflow system implemented in OCaml given in ["How to implement a spreadsheet"](https://semantic-domain.blogspot.com/2015/07/how-to-implement-spreadsheet.html), along with a test harness and a GitHub Actions build.
